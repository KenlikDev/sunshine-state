# Sunshine State

Sunshine State is an original open-world crime-action game project built with Godot 4, with Blender used for 3D asset creation.

The project aims to develop a playable, systems-driven open world through deliberate milestones, documented technical decisions, and repeatable validation. It is an independent project and will not use proprietary GTA assets, code, branding, or other protected material.

## Project Status

**Stage:** Foundation and MVP definition.

The current priority is to establish the project vision, define a realistic MVP scope, document the technical architecture and production pipeline, and prepare a minimal Godot project structure. This repository should not yet be considered a playable MVP.

## Development Principles

- Plan and review scope before implementation.
- Build in small, verifiable increments.
- Keep source code, developer documentation, and code comments in English.
- Treat Russian as a planned in-game localization, not as the language of source files or developer documentation.
- Do not claim a build or test passed unless it was actually run and its result recorded.
- Develop on focused feature branches and submit changes for review; do not work directly on `main` except for explicitly authorized repository bootstrap actions.
- Prefer original assets and clearly documented third-party resources with appropriate licenses.

## Planned Technology

- **Engine:** Godot 4
- **3D asset creation:** Blender
- **Version control and automation:** Git and GitHub Actions

Exact engine versions, platform targets, and dependencies must be pinned and validated as implementation begins.

## Documentation

Project planning and technical documentation will live under `docs/`. The MVP definition will establish measurable acceptance criteria before gameplay implementation is treated as complete.

## Validation Status

No Godot editor/import/runtime validation is claimed by this initial repository commit. Validation results will be documented when the relevant checks have actually been run.
